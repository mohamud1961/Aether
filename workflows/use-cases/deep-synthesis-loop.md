# Deep Synthesis Loop

## Purpose

Use this workflow when the project needs to turn messy evidence into a stable
engineering direction.

## Loop

1. Inventory the evidence.
2. Split work into specialist lanes.
3. Extract claims, failure patterns, mechanisms, and contradictions.
4. Run adjudication and closure.
5. Promote only the claims that survive evidence review.
6. Convert accepted findings into eval implications, variants, or workflow
   changes.

## Why It Matters

Deep synthesis is the planning/research half of the engineering loop. It keeps
agents from optimizing against the last visible failure and forces the project
to ask what the evidence actually supports.

## Output Contract

- accepted claims;
- rejected or unsupported claims;
- contradiction register;
- confidence labels;
- follow-up eval or variant recommendations.
