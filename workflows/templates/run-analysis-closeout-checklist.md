# Run Analysis Closeout Checklist

Use this when closing out a run-analysis slice.

## Inputs

- result rows or scoreboard;
- verifier and grader outputs;
- trace, receipt, or tool-observation artifacts;
- environment or runner facts;
- final answer or produced artifacts.

## Checklist

- State whether the run is valid for capability conclusions.
- Separate direct observations from inference and unknowns.
- Identify the first decisive divergence.
- Classify one primary failure class and any contributors.
- Note verifier or grader disagreements.
- Call out fake-progress onset if present.
- Name the harness component that should have changed the next rational action.
- Propose only generic fixes with a proving eval and sentinels.
- Record confidence and what evidence would falsify the conclusion.

## Closeout Output

- executive conclusion;
- validity summary;
- representative failure or pass deep dive;
- prioritized next eval or mechanism recommendation;
- missing-artifact appendix.
