# Task Packet Template

Use this template for `brief.md` inside a collaboration workspace.

```text
TASK_PACKET
- stage:
- artifact:
- objective:
- exact_question:
- why_now:
- inputs:
- preflight_requirements:
- exclusions:
- output_contract:
- collaboration_mode:
- external_agent_action:
- assigned_roles:
- upstream_artifact_inputs:
- handoff_requirements:
- evidence_expectations:
- decision_needed_from_human:
- done_condition:
```

## Notes

- Keep it short.
- One packet should map to one artifact and one question.
- If the artifact is high stakes, prefer explicit exclusions so the specialists do not sprawl.
- For Deep Synthesis artifacts, require an explicit preflight and explicit upstream handoff expectations.
