# Stage 01: Research Gathering

Purpose: build the raw evidence base before the agents start synthesizing or
implementing.

This stage was used for:

- source and artifact inventory;
- run and trace collection;
- codebase/source discovery;
- eval surface inventory;
- open-question capture;
- separating usable evidence from private or invalid material.

Exit condition: another agent can see what evidence exists, what is missing,
what cannot be published, and what should be routed into synthesis.

Subfolders:

- [skills](skills/) - operator skills used in this stage;
- [prompts](prompts/) - specialist prompts allowed in this stage;
- [artifacts](artifacts/) - evidence objects this stage should leave behind.
