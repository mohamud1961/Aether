# Stage 05: Review Repair And Publication

Purpose: attack the result before treating it as shippable or public.

This stage was used for:

- maker/checker review;
- code review closeout;
- adversarial review;
- repair loops;
- provenance review;
- public/private boundary cleanup;
- reviewer-facing evidence maps.

Exit condition: accepted findings are fixed, rejected findings are rebutted with
evidence, and publication claims match what the repo can prove.

Subfolders:

- [skills](skills/) - review and publication skills;
- [prompts](prompts/) - review support prompts;
- [artifacts](artifacts/) - finding disposition and clearance evidence.
