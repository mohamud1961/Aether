# Stage 06: Loop Operations And Continuity

Purpose: keep the project easy to resume after agents, goals, branches, and
threads move on.

This stage was used for:

- orchestrator-owned loops;
- recurring run/review/repair cycles;
- durable memory and ledger handoffs;
- worker handoff integration;
- external-state accounting;
- next-action maps.

Exit condition: the next agent can continue the project without reading every
private thread.

Subfolders:

- [skills](skills/) - orchestration and continuity skills;
- [prompts](prompts/) - project-control prompts;
- [artifacts](artifacts/) - durable state and loop receipts.
