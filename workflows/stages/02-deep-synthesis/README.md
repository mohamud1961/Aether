# Stage 02: Deep Synthesis

Purpose: turn gathered evidence into reusable engineering understanding.

This stage was used for:

- failure taxonomy;
- mechanism mapping;
- source-system dossiers;
- trajectory case studies;
- contradiction review;
- evidence-backed claim ladders;
- eval implications.

Exit condition: synthesis artifacts state what is known, what is inferred, what
is contradicted, and what needs an eval or implementation slice next.

Subfolders:

- [skills](skills/) - synthesis skills and gate roles;
- [prompts](prompts/) - specialist role prompts;
- [artifacts](artifacts/) - output shapes and public-safe examples.
