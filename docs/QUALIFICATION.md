# Aether public qualification

[![Public qualification](https://github.com/mohamud1961/Aether/actions/workflows/public-qualification.yml/badge.svg?branch=master)](https://github.com/mohamud1961/Aether/actions/workflows/public-qualification.yml)

This document records the deterministic qualification surface shipped with the public Aether release and the live GitHub qualification that re-runs it from tracked files only.

## Live current-source qualification

Every push and pull request to `master` runs:

```bash
python tools/cold_verify_public_release.py
```

That script copies **tracked files only** into a fresh temporary tree, creates a new Git index, and then runs:

```text
tools/check_public_release.py
tools/check_production_surface.py
tools/check_public_evidence.py
pytest -q tests
import aether
```

The workflow is intentionally **provider-free**. It does not need private benchmark archives, Azure credentials or model calls.

The GitHub Actions dependencies are pinned to immutable commit SHAs and checkout credentials are not persisted after source retrieval.

## Per-commit qualification receipt

Every workflow run publishes a short-lived GitHub Actions artifact named for the exact commit. It contains:

- `python.txt` — exact Python interpreter build and pip version;
- `environment.txt` — sorted full `pip freeze` of the installed qualification environment;
- `run.txt` — commit SHA, runner OS/architecture and workflow-run identity;
- `release-surface.json` / `.txt` — current tracked file count, bytes and category breakdown;
- `runtime-surface.json` / `.txt` — static import graph for the tracked production Python package.

The release-tree measurement is generated by:

```bash
python tools/release_surface_report.py \
  --json release-surface.json \
  --text release-surface.txt
```

This deliberately separates the **current checked-out release surface** from the much larger historical Git repository. Full history is provenance; it is not required to install or inspect the current runtime.

The import graph is generated by:

```bash
python tools/runtime_surface_report.py \
  --json runtime-surface.json \
  --text runtime-surface.txt
```

It parses the tracked `aether/**/*.py` files with Python's AST and computes intra-package static reachability from the canonical public roots `aether`, `aether.launch` and `aether.harbor_agent`.

**Interpretation rule:** modules not reached by this static analysis are review candidates, not automatically dead code. Optional, registry-based, uploaded or otherwise dynamic loading can be invisible to a static import graph.

## Evidence-manifest consistency gate

`tools/check_public_evidence.py` makes the public diligence index part of qualification rather than prose-only documentation.

It fails closed if, among other things:

- a referenced public evidence path disappears or escapes the repository;
- evidence IDs collide or required classification metadata disappears;
- SHA-256 fields become malformed;
- the sealed H10 aggregate/governance/verdict claims in `evidence/MANIFEST.json` drift from the sealed H10 JSON;
- the selected Luna run ID/model/reward/status/trajectory hash drift from its machine receipt;
- the workspace-boundary projection drifts from its declared source/receipt;
- the external Terra/Codex comparator loses its explicit non-causal/pending-evidence boundary.

This does **not** make selected evidence representative. It only prevents the public index from silently diverging from the machine-readable evidence it claims to summarize.

## What the production-surface guard checks

The fail-closed guard scans the current `aether/` package and current package metadata. Among other checks it rejects:

- legacy Aether/HarnessEng runtime imports;
- historical Architect/Workbench cognition modules;
- retired control tokens and runtime selectors;
- checkout-specific local paths;
- hard-coded non-loopback IP addresses;
- benchmark task identifiers derived from frozen external-to-production authorities;
- missing dynamic package dependencies;
- a missing or non-canonical console entrypoint;
- Harbor runtime/version drift;
- launch-schema drift;
- benchmark lifecycle ownership drifting away from Harbor.

The current qualified production identity includes:

- **100** production Python modules under `aether/`;

- Harbor adapter `aether.harbor_agent:AetherHarborAgent`;
- Harbor version lock `0.20.0`;
- **100** benchmark-neutrality task identifiers derived from four frozen evidence sources;
- production-surface status **VALID**.

## What this proves

These checks establish that the published production package is installable, importable and internally consistent with the current Aether ownership boundary on a clean external runner; that the deterministic public suite is green; and that the public evidence index remains bound to its referenced receipts.

They do **not** prove benchmark superiority, universal reliability, or safety. Live model behaviour, provider behaviour, benchmark environments and external evaluators remain separate empirical questions.

## Public/research boundary

The public repository deliberately separates:

- `aether/` — production runtime;
- `tests/` — production-bound deterministic qualification;
- `evidence/` — selected public-safe empirical cases and sealed aggregate evidence;
- `tracking/` — only the frozen authority artifacts needed for public verification;
- broader internal experiment archives — not automatically published.

A clean test suite and evidence-consistency gate are necessary engineering evidence. They are not substitutes for the matched live comparisons proposed in the three-month research programme.
