# Third-Party Notices

This public repository currently presents the Aether runtime capability slices
as owned HarnessEng Python interfaces, backed by repo-local evals and
provenance policy.

No third-party code notice is required for the public reviewer path unless a
future slice deliberately publishes copied or directly translated third-party
source. If that happens, add a specific notice with exact source, license, and
attribution evidence before publication.

Private source-study notes, research copies, and source-specific handoff
receipts are not part of the reviewer-facing artifact set.
