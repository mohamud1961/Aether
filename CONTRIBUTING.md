# Contributing

Humans and coding agents follow the same rules here.

1. **Map before you build.** For any non-trivial change, write down what exists, what matches
   the [vision](docs/VISION.md), what violates it, what is missing, and the smallest next step.
2. **One logical change per commit.** Code, tests and docs for that change land together. Tests
   pass at every commit.
3. **No Fake Work.** Green means real execution. See [docs/no-fake-work.md](docs/no-fake-work.md).
4. **Experiments are pre-registered.** A prediction, a falsifier and named sentinels are written
   before any trial. Failed predictions are recorded, not reinterpreted.
5. **Evidence, not narration.** A pull request says what changed and shows the command output
   that proves it.
6. **Review is independent.** Nobody approves their own change.
