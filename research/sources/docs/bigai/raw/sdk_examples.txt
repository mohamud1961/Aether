TongAgents SDK 示例¶

本节包含了使用 TongAgents SDK 开发的各种智能体示例，帮助您快速了解如何使用 SDK 构建不同类型的智能体应用。

可用示例¶

以下是当前提供的示例：

知识库工具调用 - 本示例展示如何集成多知识库工具，实现精准语义搜索问答功能全面。
嵌套工作流 - 示例利用子流程转换数字格式判奇偶后聚合统计全面展示工作流功能
天气查询智能体 - 一个简单的天气查询智能体，展示了如何使用 TongAgents SDK 构建基础的信息查询服务。
Pydantic解析智能体 - 该示例演示了如何利用 TypedReactAgent 验证解析 LLM 返回的 JSON 数据。
电影售票智能体 - 本示例展示电影售票智能体，通过意图分类自动处理订票和聊天请求。
监控报警智能体 - 本示例通过一个实时监控及分级处理告警的Agent示例，展示TongAgent框架应对实时场景需求的能力，可以处理实时紧急事件，而不被其他事件所阻塞
办公助理互动 - 利用Gradio实现虚拟办公助理对话交互，集成工具调用。
语音交互智能体 - 本示例展示框架多模态交互能力，实现通过Web的语音采集与反馈，呈现实时音频响应互动。
多智能体协作 - 本示例通过多智能体分工合作的工作流组，分别承担设计、研发和运维任务，展示了框架高效整合复杂任务的能力。
如何使用这些示例¶

每个示例都包含了详细的代码实现和使用说明，您可以按照指南一步步学习如何构建和部署相应的智能体。这些示例旨在展示 TongAgents SDK 的核心功能和最佳实践。

贡献新示例¶

如果您开发了有价值的 TongAgents 应用并希望与社区分享，欢迎提交您的示例。请确保您的示例代码清晰、注释充分，并包含必要的使用说明。
