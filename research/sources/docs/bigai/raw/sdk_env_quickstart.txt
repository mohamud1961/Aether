快速开始
Env SDK¶

通常，Agent的开发者希望快速的在超出命令行的复杂环境调试其构造的Agent。

现有的云平台提供了易于调试和交互的用户界面，但开发者失去了对底层实现细节的把控；现有的Agent开发框架对不同诉求的开发者提供了不同复杂性的接口，允许开发者修改Agent的实现细节，但缺少了用于调试的复杂环境。

有时，为了验证Agent的效果，开发者投入环境的开发时间和精力甚至超过了开发Agent本身。为此，TongAgents提供了Env SDK，为用户提供了开箱即用的复杂场景，以用于调试、评估、演示其开发的Agent的性能和表现。

快速开始¶
安装¶

TongEnv 安装非常简单：

pip
uv
pip install tong-env


(Python 3.11或3.12)

以上将安装 tong_env 包、核心依赖项以及使用 TongEnv 中所有模型所需的库。如果您只想使用特定模型，可以安装"精简安装"的 TongEnv。

精简安装¶

TongEnv提供了一系列预定义的复杂场景，用户可以方便的进行选择和使用。

比如，用户只需要使用WebEnv，可以安装：

pip
uv
pip install tong-env


此时，将不会安装TongEnv中除WebEnv外的其他复杂场景及其所需的依赖。
