知识库创建¶

创建特定类型的知识库，创建后默认为空

方法	URI
POST	/api/v1/knowledge/create
请求参数¶
Header¶
参数	取值	说明
Content-Type	application/json	指定请求正文的数据格式。当值为 application/json 时，表明请求体（Body）内容以 JSON 格式组织，服务端将按 JSON 规范解析请求参数。
X-TraceId	string	traceId
Authorization	Bearer $AccessToken	用于验证客户端身份的访问令牌
Query Params¶

无

Request Body¶
参数	类型	说明	备注
type	string	知识库的种类，目前支持MilvusVectorStore, ChromaVectorStore，EsVectorStore	MilvusVectorStore, ChromaVectorStore, EsVectorStore
user_id	string	用户的唯一标识	USER_ID
name	string	可选，知识库名称，用于知识库信息标记以及模型调用	"default_name"
description	string	可选，知识库内容和用途描述，用于知识库信息标记以及模型调用	"百科全书知识库"
endpoint	string	可选，对于私有化API服务部署，指定数据库服务地址	"http://127.0.0.1:9000"
params	map	可选参数	
params.search_limit	int	可选参数，知识库默认检索返回文档数量上限，默认5	5
params.embedding_function	string	可选参数，用于做embedding 的方法名，可选：all-MiniLM-L6-v2, bge-large-zh-v1.5, 默认使用bge-large-zh-v1.5	"bge-large-zh-v1.5"

样例数据：

{

  "type": "MilvusVectorStore",

  "user_id": "string",

  "name": "业务wiki知识库",

  "description": "业务系统设计与文档",

  "endpoint": "http://127.0.0.1:9000",

  "params": {"search_limit": 10}

}


响应参数¶
参数	类型	说明	备注
id	string	生成的知识库ID	"KNOWLEDGE_ID"

样例数据：

{

  "id": "KNOWLEDGE_ID"

}


状态码¶
状态码	说明
200	成功创建知识库
400	请求参数不合法
