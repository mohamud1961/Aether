文档重试¶

对知识库中已经存在的文档进行重新处理。

方法	URI
POST	/api/v1/knowledge/{knowledge_id}/rebind
请求参数¶
Header¶
参数	取值	说明
Content-Type	application/json	指定请求正文的数据格式。当值为 application/json 时，表明请求体（Body）内容以 JSON 格式组织，服务端将按 JSON 规范解析请求参数。
X-TraceId	string	traceId
Authorization	Bearer $AccessToken	用于验证客户端身份的访问令牌
Path Params¶
参数	类型	说明	备注
knowledge_id	string	知识库唯一标识	"KNOWLEDGE_ID"
Query Params¶

无

Request Body¶
参数	类型	说明	备注
file_ids	list	需要加入的文档ID列表	["1", "2", "3"]
params	map	可选，文档处理的额外参数，可配置文档切分逻辑，包含 chunk_size，chunk_overlap，separators三个参数字段	
params.chunk_size	int	文档切分大小，int 类型，默认为1000	1000
params.chunk_overlap	int	文档切分重叠大小，int 类型，默认为100	100
params.separators	list	文档切分分隔符，list 类型，默认为["\n\n", "\n", " ", ".", ","\, "\u200b", "\uff0c", "\u3001", "\uff0e", "\u3002", ""]	["\n", " "]

样例数据：

{

  "file_ids": [

    "string"

  ],

  "params": {

    "chunk_size": 1000,

    "chunk_overlap": 100,

    "separators": [

        "\n\n",

        "\n",

        " ",

        ".",

        ",",

        "\u200b",

        "\uff0c",

        "\u3001",

        "\uff0e",

        "\u3002",

        ""

    ]

  }

}


响应参数¶

返回201状态码和成功信息。文档加入成功后会异步的处理文档内容，以支持后续的检索操作。

参数	类型	说明	备注
msg	string	详细信息	"Documents added."

样例数据：

{

  "msg": "Documents added."

}


状态码¶
状态码	说明
201	请求成功
400	请求参数错误
404	请求的知识库不存在
