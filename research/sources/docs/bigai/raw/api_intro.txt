TongAgents API介绍¶
概述¶

TongAgents API 是一个基于 HTTP 协议的 API，旨在为 TongAgents 提供强大的智能体管理、对话管理和知识库管理等能力。通过该 API，用户可以轻松地创建和管理智能体，进行会话交互，以及维护和更新知识库等操作。

主要内容¶
1. API文档¶

接口文档详细描述了与 智能体相关的各类 HTTP 接口，包括 智能体管理，对话管理等，工作流管理，以及知识库管理等。具体接口文档包括：

智能体相关接口：
创建智能体
更新能能体
获取智能体详细信息

删除智体体

会话相关接口：

创建智能体会话
智能体对话

智能体会话查询

工作流相关接口：

创建工作流
获取工作流

更新工作流

知识库相关接口：

创建知识库
添加文档
上传文件
2. SDK 文档¶

SDK 文档提供了 TongAgents SDK 的使用方法和相关接口的详细介绍，包括 Agent 管理和对话管理两大功能模块。具体内容包括：

Agent 管理：
AgentClient 类

主要方法：创建 Agent、更新 Agent、获取 Agent、绑定 Agent

对话管理：

ConversationClient 类
主要方法：创建会话、发送聊天请求、检索会话消息、异步流式对话、关闭客户端连接
3. 示例代码¶
SDK示例代码

示例代码展示了如何使用 TongAgents SDK 进行 Agent 管理和对话管理的完整流程，包括初始化客户端、创建 Agent、创建会话、发送聊天请求以及关闭客户端连接等步骤。用户可以通过阅读示例代码快速上手 SDK 的使用。

使用指南¶
阅读API文档：了解各类API的功能、请求参数、响应参数以及请求示例，确保对接口有清晰的认识。
查阅 SDK 文档：熟悉 SDK 的使用方法和相关接口，了解如何初始化客户端、调用接口以及处理响应。
运行示例代码：通过运行示例代码，体验 SDK 的实际使用效果，并根据自身需求进行修改和扩展。
