更新日志
2.0.0¶
核心能力抽取到开源 chuang_agent，tongagents 作为企业版在其上增强，形成清晰的开源/闭源分层
工具层统一：ToolManager / MCPClient / MCPToolManager / Tool 基类 / ToolParameters 在 chuang_agent 统一实现并被 tongagents 复用（tool_id 映射、远程工具同步、MCP 传输方式与错误处理等）
chuang_agent 移除 workflow/node 相关概念；tongagents 保留并增强 workflow 引擎
新增 WorkFlowEnv：基于 DefaultEnvironment 的企业版运行环境，支持在环境级别管理/运行 workflow
