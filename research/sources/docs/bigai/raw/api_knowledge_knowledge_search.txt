知识库检索¶

根据query检索知识库内容，返回符合检索条件的文档内容

方法	URI
POST	/api/v1/knowledge/{knowledge_id}/search
请求参数¶
Header¶
参数	取值	说明
Content-Type	application/json	指定请求正文的数据格式。当值为 application/json 时，表明请求体（Body）内容以 JSON 格式组织，服务端将按 JSON 规范解析请求参数。
X-TraceId	string	traceId
Authorization	Bearer $AccessToken	用于验证客户端身份的访问令牌
Path Params¶
参数	类型	说明	备注
knowledge_id	string	知识库唯一标识	"KNOWLEDGE_ID"
Query Params¶
参数	类型	说明	备注
query	string	知识库检索语句	
Request Body¶
参数	类型	说明	备注
limit	int	可选，返回的文档数上限	5
响应参数¶

返回json array，每一个json对象包含字段如下

参数	类型	说明	备注
score	float	文档匹配相似度分数	0.65
document	map	文档内容	包含metadata, content, id 字段

样例数据：

[

  {

    "score": 0.65,

    "document": {

      "metadata": {

        "source": "document.pdf",

        "page": 2

      },

      "content": "This is the content of the document.pdf",

      "id": "456481218743015592"

    }

  }

]


状态码¶
状态码	说明
200	请求成功
404	请求的知识库不存在
