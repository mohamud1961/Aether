二维码分享¶

对于已经发布的智能体，开放平台提供二维码分享功能
- 点击个人空间页签，在智能体列表中，找到已发布的智能体
在发布平台这一列，找到网页按钮的图标，在其右侧连续点击5次
生成二维码图标 

- 点击二维码图标选择复制链接
在链接里面找到userid和token
- http请求会话api


http请求注意事项
url 地址:
https://tongagents.mybigai.ac.cn/api/v1/agent/conversation/chat
header 选项：
content-type: text/event-stream; charset=utf-8
