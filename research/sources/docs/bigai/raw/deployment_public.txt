公共编排服务¶

TongAgents 公共编排服务提供云端托管的智能体编排能力，无需自行部署，通过 API 即可快速接入。

服务地址¶
服务	地址
编排平台	https://tongagents.builder.mybigai.ac.cn
API 端点	https://api.tongagents.com/v1
服务能力¶
1. 零代码平台¶

通过可视化界面快速构建智能体：

可视化编排：拖拽式工作流设计
预置模板：丰富的行业模板
一键部署：即时发布
2. API 调用¶
from tongagents import AgentClient



client = AgentClient(

    api_key="YOUR_API_KEY",

    base_url="https://api.tongagents.com/v1"

)



response = client.chat(

    agent_id="agent_xxx",

    message="帮我写一段代码"

)
