Knowledge 知识库¶

TongAgents 开放了知识库访问相关API，用户可通过API 对用户所创建的知识库进行操作。

知识库管理接口¶
请求方法	URI	功能说明
POST	/api/v1/knowledge/create	创建知识库
POST	/api/v1/knowledge	list已有知识库
GET	/api/v1/knowledge/{knowledge_id}	获取知识库元信息
POST	/api/v1/knowledge/{knowledge_id}	为知识库添加文档
POST	/api/v1/knowledge/{knowledge_id}/rebind	文档重试
GET	/api/v1/knowledge/{knowledge_id}/files	知识库文档列表
POST	/api/v1/knowledge/{knowledge_id}/files/{file_id}/delete	删除知识库文档
POST	/api/v1/knowledge/{knowledge_id}/search	检索知识库
POST	/api/v1/knowledge/{knowledge_id}/update	更新知识库
POST	/api/v1/knowledge/{knowledge_id}/delete	删除知识库
文件管理接口¶
请求方法	URI	功能说明
POST	/api/v1/files/upload	上传原始文件
POST	/api/v1/files	获取已有文件信息
POST	/api/v1/files/delete	删除已上传的文件
GET	/api/v1/files/{file_id}	获取给定文件内容
