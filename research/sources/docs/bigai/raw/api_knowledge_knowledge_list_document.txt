知识库文档列表¶

根据传入参数条件，查询知识库中的文档信息

方法	URI
GET	/api/v1/knowledge/{knowledge_id}/files
请求参数¶
Header¶
参数	取值	说明
Content-Type	application/json	指定请求正文的数据格式。当值为 application/json 时，表明请求体（Body）内容以 JSON 格式组织，服务端将按 JSON 规范解析请求参数。
X-TraceId	string	traceId
Authorization	Bearer $AccessToken	用于验证客户端身份的访问令牌
Query Params¶
参数	类型	说明	备注
page_size	integer	每页数量	默认值为10
page_num	integer	页码，从1开始	默认值为1
Request Body¶

无

响应参数¶
参数	类型	说明	备注
page_size	integer	每页数量	
page_num	integer	页码	从1开始
total_size	integer	文件总数	
data	list	文件列表	
data[0].id	string	文档ID	
data[0].id	string	文档名称	
data[0].size	integer	文档大小	单位字节
data[0].status	string	文档状态	success:成功; pending:待处理; in_progress:处理中; failed:失败
data[0].creation_time	integer	文档创建时间	时间戳

状态码¶
状态码	说明
200	请求成功
404	请求的知识库不存在
