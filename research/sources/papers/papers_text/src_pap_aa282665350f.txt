Abstract
Large Language Model (LLM) agents have developed rapidly in recent years to
solve complex real-world problems using external tools. However, the scarcity
of high-quality trajectories still hinders the development of stronger LLM agents.
Most existing works on multi-turn dialogue synthesis validate correctness only at
the trajectory level, which may overlook turn-level errors that can propagate during
training and degrade model performance. To address these limitations, we introduce
ToolMind, a large-scale, high-quality tool-agentic dataset with 160k synthetic data
instances generated using over 20k tools and 200k augmented open-source data
instances. Our data synthesis pipeline first constructs a function graph based on
parameter correlations and then uses a multi-agent framework to simulate realistic
user–assistant–tool interactions. Beyond trajectory-level validation, we employ fine-
grained turn-level filtering to remove erroneous or suboptimal steps, ensuring that
only high-quality reasoning traces are retained. This approach mitigates error ampli-
fication during training while preserving self-corrective reasoning signals essential
for robust tool-use learning. Models fine-tuned on ToolMind show significant
improvements over baselines on τ-bench, τ 2-bench, and BFCL-v4. The dataset is
available athttps://huggingface.co/datasets/Nanbeige/ToolMind.

1 Introduction
Large Language Models (LLMs) have adopted Function Calling (FC) paradigm to interact with
external environments, significantly expanding their capacity to solve complex real-world tasks [23,
14]. This capability hinges on the model’s proficiency in tool use, which requires reliable interpretation
of user instructions, appropriate function selection, and precise parameter generation. A data-centric
approach has proven effective in enhancing such capabilities, typically requiring large-scale, high-
quality datasets with diverse and accurate function-call demonstrations.
Recent studies have actively synthesized data for various function calling scenarios [8, 17], spanning
diverse application domains and interaction modalities such as selection from large toolsets, parallel
function calls, and rejection of unspecified requests [10, 12, 18]. However, existing datasets have
several critical limitations: limited scale, the absence of explicit reasoning traces, a lack of multi-turn
interactions, and insufficient query diversity. These issues highlights the importance of high-quality,
large-scale datasets to develop robust and generalizable tool-use models and agents.
A key challenge in constructing high-quality datasets lies in capturing the dynamic nature of real-
world user–assistant interactions. First, user requests are often under-specified, lacking sufficient
parameters for task completion (e.g., a query like “What’s the weather in Beijing?” does not specify
a time frame). Second, effective interaction requires an ongoing clarification process, in which the
assistant can proactively request missing information from the user. Current open-source synthetic
datasets rarely capture these dynamics, leading to models struggling with such scenarios.
In this work, we introduce ToolMind, a reasoning-enhanced tool-use dataset comprising 360k samples.
It integrates 160k assistant response turns synthesized through multi-agent simulations and 200k
augmented turns adapted from open-source data. To ensure diversity, we collect 20k functions
from open-source datasets and construct a function graph that captures inter-parameter correlations.
Function chains are then sampled via random walks on this graph to synthesize user intents. Then, we
employ a multi-agent framework for dialogue generation, orchestrating three dedicated roles—user,
agent, and tool—each instantiated by a language model to capture the dynamics and complexities of
real-world tool-use interactions. Finally, we apply a rigorous two-stage filtering process, comprising
both trajectory-level and turn-level quality checks, to ensure that all training samples contain only
valid conversation turns.
Our experiments demonstrate the effectiveness of the ToolMind dataset in enhancing the tool-use
capabilities of LLMs. With supervised fine-tuning (SFT), models of various scales show significant
improvements over baselines across multiple benchmarks, including BFCL-v4 [11], τ-bench [20],
andτ 2-bench [1]. Our main contributions are summarized as follows:
• High-Quality Tool-Use Dataset.We introduce ToolMind, a large-scale, high-quality tool-
use dataset comprising 360k samples that effectively addresses the key limitations of existing
datasets—namely in scale, reasoning traces, multi-turn interactions, and query diversity.
•Data Synthesis and Quality Filtering Pipeline.We develop a novel data synthesis pipeline that
constructs a function graph based on parameter correlations and employs multi-agent simulations
with three dedicated roles (a user, an assistant, and a tool), which better capture the dynamic nature
of real-world tool-use interactions. A rigorous two-stage filtering process is further applied to
ensure high data quality.
• Effectiveness of Large-Scale Simulation.We show that ToolMind delivers significant and
consistent performance improvements across models of various scales. These results empirically
validate that large-scale synthetic data generated from simulated environments can serve as an
effective alternative to real-world data for achieving substantial gains in model performance.

3.2 Multi-Agent Multi-Turn Trajectory Synthesis
Based on the sampled function chains, we synthesize user intents to represent realistic user goals. A
user intent represents the underlying goal that a user aims to achieve, rather than the exact query they
pose. This distinction provides greater flexibility in modeling user behavior, as users often express the
same intent in diverse ways. Since the tools are not executable in our setup, we employ a simulation
framework to generate responses. The trajectories are created through a multi-agent simulation that
involves three distinct agents:
• User Agent: Initiates the interaction by asking questions based on synthesized intent and drives
the conversation forward.

• Assistant Agent: Responds to the user’s queries, provides guidance, asks for clarification, or calls
external functions when needed.
• Tool Agent: Simulates the execution of a function invoked by the assistant, returning tool responses
based on simulated outputs.
These three agents operate in an iterative loop: the user agent poses a query, the assistant agent
responds, and the tool agent simulates feedback when required. The process continues until a
predefined turn limit or stopping condition is reached. This simulation produces a diverse set of
interaction trajectories that serve as training data for modeling rich user–assistant–tool dynamics.
Empirical results demonstrate that even without real-world interaction, the large-scale synthetic data
generated from these simulations significantly improves model performance. The flexibility and
diversity of the simulated conversations provide valuable insights for training models in complex,
multi-agent systems. For a detailed example of the generated data, see Appendix B.
3.3 Quality Filtering
To ensure that the synthesized interactions provide reliable learning signals, we apply a two-stage
quality filtering process: trajectory-level filtering that maintains goal alignment and coherence,
followed by turn-level filtering that removes erroneous or misaligned steps.
3.3.1 Trajectory-Level Filtering
Given the predefined user intents (defined in the previous section), the user agent first judges whether
the task is completed or not during the process of multi-turn interaction. Then, a second LLM
evaluates goal coverage, coherence, and cross-turn relevance. Only trajectories that both align with
the intent and exhibit a coherent flow are retained, while the rest are discarded. This stage produces a
high-quality pool of trajectories for finer-grained filtering.
3.3.2 Turn-Level Filtering
Since trajectory-level filtering operates at a coarse granularity, it cannot effectively isolate erroneous
turns within otherwise coherent trajectories. Trajectories may still contain erroneous or misaligned
turns—such as failed intermediate attempts, tool calls based on incorrect assumptions, or role drift in
user/tool messages. To further improve data quality, we address these remaining issues by applying
a separate LLM-based judge to each turn. The model then masks invalid or role-inconsistent steps
and retains only correct procedural actions, ensuring the final training data targets effective problem
solving and precise tool use.

4 Experiments
This section presents the performance of models of varying sizes after supervised fine-tuning (SFT)
on our dataset. We first present the fine-tuning setup and then evaluate the resulting models against
the baselines on widely-used tool-calling benchmarks.
4.1 Experimental Setup
Model and Fine-tuning Setup.We perform supervised fine-tuning (SFT) on Qwen3-8B, and
Qwen3-14B [19]. The training is conducted using OpenRLHF [6] framework with a sequence length
of 64k, a global batch size of 64, a learning rate of 5e-6, and a warmup ratio of 0.03.
Benchmarks.We evaluate our models on three widely used tool-calling benchmarks: BFCL-
v4 [11], τ-Bench [20], and τ 2-bench [1]. For BFCL-v4, we use the official evaluation setup for
Qwen3 and benchmark our model against larger-scale models on the official leaderboards as of
October 2025. For a comprehensive comparison, we incorporat results from both open-source models
DeepSeek-V3 [7], DeepSeek-R1-0528 [4], Qwen3-235-instruct [19], Kimi-K2-Instruct [16]
and closed-source models GPT-4o-2024-11-20, GPT5-2025-0807, and Gemini2.5-Pro [3]. For
τ-Bench and τ 2-Bench, we used GPT-4o as a user simulator and evaluate performance by directly
comparing the model before and after fine-tuning.

several larger-scale open-source and closed-source models. Similarly, on theτ-bench andτ 2-bench
benchmarks, both Qwen3-8B and Qwen3-14B achieve substantial improvements in their average
score after training on ToolMind. These results demonstrate the effectiveness of the ToolMind dataset
in improving model tool-use capabilities.

Ablation Study.To evaluate the effectiveness of each component in ToolMind, we conduct an
ablation study on Qwen3-8B. The study comprises the following configurations: (a) using only
synthesized data, (b) using synthesized data without turn-level quality filtering, and (c) using only
data augmented from open-source datasets. The experimental results, shown in Table 4, demonstrate
that the open-source augmented data contribute to significant performance improvements on τ-bench
and τ 2-bench, while the graph sampling-based synthetic data lead to major gains on BFCL-v4,
and the turn-level quality filtering significantly enhances the model performance. Moreover, the
model trained on the combined dataset achieves the best results across nearly all evaluation metrics,
demonstrating that each component of ToolMind is integral and effective.
5 Conclusion
This paper presents ToolMind, a large-scale dataset designed to address data scarcity in tool-use for
Large Language Models. Built through graph-based function sampling and multi-agent trajectory
synthesis, ToolMind offers diverse, realistic function-calling trajectories with explicit reasoning
traces. Experimental results demonstrate that models fine-tuned on ToolMind achieve consistent and
significant improvements across multiple benchmarks. Our work highlights the value of high-quality
synthetic data for advancing tool-use capabilities and provides a valuable resource for future research.
