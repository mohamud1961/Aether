# Codebase Repository

This directory contains the source code for various agentic harnesses and frameworks under research.

**Last Updated:** 2026-03-31

## Directory Structure

- **[KIRA/](./KIRA/)**: Source code for the Terminus-KIRA agentic harness.
- **[a-evolve/](./a-evolve/)**: Research mirror for the `a-evolve` agent-evolution codebase.
- **[deepagents/](./deepagents/)**: Source code for the DeepAgent harness, including its Harbor integration and core libraries.
- **[langchain/](./langchain/)**: Research mirrors for LangChain evaluation repos, currently `agentevals` and `openevals`.
- **[quarantine/](./quarantine/)**: Informal or high-risk source mirrors kept separate from the main trusted reference set.

## Purpose
These codebases serve as reference implementations for analyzing architectural patterns, tool gateway designs, and state management strategies.
