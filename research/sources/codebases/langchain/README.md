# LangChain Eval Mirrors

This directory contains research mirrors of public LangChain evaluation repositories.

## Included repositories

- `agentevals/`: agent-trajectory-focused evaluators and utilities.
- `openevals/`: broader evaluator toolkit for LLM apps, including judge-style and custom evaluator patterns.

## Why these are here

These mirrors are for research and eval-design reference only. They are not part of the live harness runtime and should not shape core interfaces prematurely.
