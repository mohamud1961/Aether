Recently @supermemory achieved 99% on LongMemEval.

The problem is that memory benchmarks were created when LLMs had a very small context window.

For example LongMemEval_M is ~1.5M tokens.

Which is almost inside the Opus 4.6 context window.

From what I understand, current best benchmark is BEAM with 10M context window. So I'm evaluating all new memory systems based on their score in there.

Excited to see how @supermemory will score! I am sure it's gonna do well!
