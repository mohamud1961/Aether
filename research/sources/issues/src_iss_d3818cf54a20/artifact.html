    Describe the bug

    I'm using gpt-4.1 with one of my agents, and occasionally it will generate invalid JSON for tool call inputs - example below. When this happens, the Agents SDK tries to parse it as normal, and ends up throwing an error like the following.

    I understand that the LLM generating invalid JSON is pretty much par-for-the-course, but it feels like this is something that the SDK should be able to handle and maybe retry the tool call? I actually ported this Agent from Langchain/Langgraph, with the exact same model, prompts and tools, and I've never seen this error surface, so it must be doing something different to handle this.

    Error stack:
