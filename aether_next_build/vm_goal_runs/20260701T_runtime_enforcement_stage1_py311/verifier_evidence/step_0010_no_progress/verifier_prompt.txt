False-positive traps:

- A query that counts classes, enrollments, or departments instead of distinct currently enrolled students.
- A query that uses GROUP_CONCAT but omits DISTINCT or aggregates only the department that satisfies the student threshold.

- A query that looks syntactically plausible but uses invented namespaces, wrong current-state semantics, or misses the full-professor condition.
