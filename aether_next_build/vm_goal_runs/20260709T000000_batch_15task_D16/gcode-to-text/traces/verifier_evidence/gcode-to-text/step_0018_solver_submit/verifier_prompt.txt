Role: Frozen-state reviewer for the current workspace state.

Task-specific success criteria:
- /app/out.txt exists and its contents exactly match the text that /app/text.gcode will print.
- The inspected G-code and the output file provide direct, inspectable evidence for the same answer.
- There is no visible mismatch in spelling, spacing, punctuation, or line structure that would change the printed text.

Required evidence for completed:
- Directly inspect /app/text.gcode raw content around the candidate text and any surrounding toolpath or comment lines that support the derivation.
- Directly inspect /app/out.txt contents, not merely file existence or size.
- Compare the inspected G-code-derived text with the contents of /app/out.txt using the workspace state itself.
- If needed, inspect additional nearby G-code lines to resolve whether a readable string is actually printed text or merely metadata.

False-positive traps:
- Accepting file existence alone as completion.
- Accepting a string copied from a filename, title, object label, or isolated comment without corroboration from surrounding G-code.
- Accepting an output file with the right shape but the wrong text, wrong spacing, or extra characters.
- Accepting solver-reported evidence without direct inspection of the current files.
- Accepting a repeated parse of /app/out.txt alone as if it independently confirms the G-code source.

Verdict guidance:
- Return completed only when direct inspection of both files shows that /app/out.txt matches the text actually implied by /app/text.gcode.
- Return incomplete or needs repair when the output file is missing, mismatched, empty, or contains extra formatting that changes the answer.
- Return uncertain or blocked only if the required file inspection itself cannot be performed with the available tools or the workspace state is inaccessible.

Feedback guidance:
- State exactly what was inspected, such as the relevant G-code lines and the current contents of /app/out.txt.
- Explain the mismatch concretely: wrong text, extra whitespace, missing newline, or evidence that the answer was inferred from metadata instead of toolpath content.
- Say what state change would resolve the issue, for example rewriting /app/out.txt with the exact derived text.
