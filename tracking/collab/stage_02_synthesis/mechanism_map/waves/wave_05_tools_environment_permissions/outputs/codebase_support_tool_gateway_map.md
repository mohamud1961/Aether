## Cross-family mechanism candidates (support-level)

1. Dynamic execution exposure gating is a repeated family (deepagents runtime execute filtering; KIRA safety checks; a-evolve task-enabled MCP filtering).
2. CWD/workdir discipline is explicit but heterogeneous (deepagents absolute-path doctrine, KIRA workspace-root defaults and validation, a-evolve independent shell calls and optional workdir helpers).
3. Permission doctrine spans three separable layers: command-policy allow/deny, approval/HITL gates, and sandbox/container isolation. These should not be collapsed into a single "safety" mechanism.
4. Browser/MCP integration presence does not imply robust permission doctrine by itself; robust doctrine appears only where trust/allowlist/approval and state boundaries are explicit.

## Limits

- This support artifact does not promote mechanism conclusions by itself.
- BigAI entries remain behavioral reconstruction and are not source-backed implementation claims.
- Quarantine claw-code remains archive-pressure evidence, not first-class mirrored runtime equivalence.
