- terminology_and_definition_notes:
  - `2512.13564` is the clearest definitional source for separating:
    - working memory: active within-episode context management
    - factual memory: persistent declarative facts
    - experiential memory: durable task-derived strategy/skill traces
    - context engineering: resource-management and interface-assembly methodology rather than a synonym for memory
  - `2512.05470` sharpens repository vocabulary:
    - history: immutable source-of-truth log
    - memory: persistent but mutable indexed view
    - scratchpad: temporary workspace that may later be promoted or archived
  - `src_pap_b191e17f02bb` sharpens structured workspace vocabulary:
    - fixed segment / stable anchor
    - long-term summary block
    - recent working-memory block
  - OpenAI docs sharpen substrate vocabulary:
    - sessions: external conversation history storage
    - compaction: opaque state-carrying next-window reduction, not human-readable long-term memory
  - Microsoft docs sharpen checkpoint vocabulary:
    - checkpoint: explicit saved workflow state for later resume or rehydration
