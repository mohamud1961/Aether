- Lane: `codebase/source-reconstruction`

## Attribution Implications
- Keep `context-compaction failure`, `stale retrieval`, `session-state drift`, and `workspace/branch drift` as separate families.
- Keep runtime allocator-memory failures separate from coding-agent context/memory failures.
- Keep BigAI mechanism claims labeled `behavioral reconstruction`.
