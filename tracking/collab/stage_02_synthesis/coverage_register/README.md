# Coverage Register

This directory holds the canonical Deep Synthesis coverage-control surface.

Its purpose is to stop strong wave prose from being mistaken for actual deep coverage.

## Canonical file

- `tracking/collab/stage_02_synthesis/coverage_register/current_status.md`

## What it should track

- completed waves
- active support tracks
- system-dossier status
- trajectory-case-study status
- formal-dossier status
- informal-cluster status
- eval-dossier status
- accepted carry-forward warnings
- material gaps that still block artifact completion

## Operating rule

Update the coverage register after every accepted serious wave.
