AETHER / NEXT-GENERATION AI AGENT

Make the model
the limit.

The next generation of models needs a next generation of agent.

How much model capability is lost in the system around it? Aether is an extensible computer for AI agents, designed so model progress can become agent progress. The model leads; the system provides tools, memory and bounded execution, and lets the model build capabilities it needs.

01 / THE SYSTEM

THE RESEARCH THESIS

More capable agency should not require more hidden intelligence around the model, or less control around its actions.

Aether is testing whether a model can lead more of its own work while the system stays bounded, inspectable and reliable.
